# HelpChess

Отдельное шахматное приложение для Android (Kotlin + Jetpack Compose) со встроенным движком.
Оно **не читает экран и не вмешивается в chess.com** — вы повторяете ходы партии на доске HelpChess.

## Что умеет

- **Подсказка «куда ходить»**: лучший ход (зелёная стрелка), ещё два варианта (жёлтые), оценка и ожидаемый ответ соперника.
- **Куда пойдёт соперник**: на его очереди показывает три самых вероятных хода (красные стрелки).
- **Угрозы**: если соперник что-то грозит (взять фигуру, поставить мат), показывает красную стрелку и описание.
- **Разбор хода соперника и вашего**: лучший ход / хороший / неточность / ошибка / зевок и что было сильнее.
- **Профиль соперника**: средняя потеря, число зевков и ошибок, стиль и совет, как играть против него.
- **Режимы**: зеркало партии (вводите ходы за обе стороны) или игра против встроенного бота (5 уровней).
- Отмена хода, переворот доски, загрузка позиции из FEN, настройка скорости анализа (0.3–3 с).

Движок написан на чистом Kotlin (negamax + alpha-beta, таблица транспозиций, нулевой ход, LMR,
поиск тихих ходов, MultiPV) и проверен перфт-тестами на эталонных позициях. Анализ глубиной около 7 полуходов занимает меньше секунды.

## Сборка APK

1. Установите Android Studio (Ladybug или новее) — она сама скачает Android SDK.
2. `File → Open` и выберите папку `HelpChess`, дождитесь синхронизации Gradle.
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
   Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

Из терминала (нужны JDK 17 и Android SDK, переменная `ANDROID_HOME`):

```
./gradlew assembleDebug
```

Установка на телефон: скопируйте `app-debug.apk` на устройство и разрешите установку из неизвестных источников.
